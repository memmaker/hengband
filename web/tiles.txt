tiles.webp: Adam Bolt's 16x16 tile set (the "new" graphics of Zangband /
Hengband, graf-new.prf), 1024x1072, 64 x 67 tiles: Hengband's official
release sheet, 16x16.bmp + mask.bmp (mask white = transparent) of
heng-graf-16x16.zip (GitHub release asset of 3.0.1.29-Beta, linked from
https://hengband.github.io/download.html; 2002), lossless. Columns 32-63
are Hengband's additions that graf-new.prf addresses.
Tiles by Adam Bolt; pref file by Robert Ruehlmann; Hengband ids upstream.
Stand-ins for the gaps: lib/pref/graf-ab.prf (web/mkgraf-ab.py).

tiles-8x8.webp: Hengband's own 8x8 set, lib/xtra/graf/8x8.bmp of the
hengband.xtra submodule (= the 3.0.2.4-Beta release zip; multilockon123's
update of the old 8x8 tiles, 512x792, opaque, grey (48,48,48) = unused),
graf-xxx.prf ("old" graphics). Stand-ins: lib/pref/graf-8x8.prf
(python3 web/mkgraf-ab.py 8x8).

tiles-shb.webp: Shockbolt 64x64 (Raymond Gaustadnes; Angband 4.2
lib/tiles/shockbolt/64x64.png via ~/Games/tactical-angband, same file as
FrogComposband's web/tiles.webp), 8192x2048, lossless. Mapping and stand-ins:
lib/pref/graf-shb.prf (python3 web/mkgraf-shb.py).
